# ComfyUI ROCm Launcher 图标使用说明

本目录存放项目的 SVG 图标原型，统一采用「节点工作流三角」品牌符号：中心紫→品红渐变节点方块，三条圆头连线外接三枚节点圆点，整体呈倒三角，呼应 ComfyUI 节点式工作流与 Launcher 的启动语义。

## 文件清单

| 文件                    | 适用场景                 | 规格          | 说明                                           |
| ----------------------- | ------------------------ | ------------- | ---------------------------------------------- |
| `app-icon.svg`        | 任务栏、标题栏、窗口图标 | 256 网格      | 深紫渐变圆角底 + 全彩品牌符号，应用主图标      |
| `tray-icon-light.svg` | 系统托盘（深色任务栏）   | 24 网格，单色 | 透明底白色图形，小尺寸高辨识                   |
| `tray-icon-dark.svg`  | 系统托盘（浅色任务栏）   | 24 网格，单色 | 同构深紫蓝单色版                               |
| `file-icon.svg`       | 文件资源管理器关联图标   | 256 网格      | 白纸文档 + 折角 + 渐变品牌符号，与主图标同语言 |

## 配色规范

| 用途             | 色值                                      |
| ---------------- | ----------------------------------------- |
| 渐变主色         | `#A78BFA` → `#8B5CF6` → `#EC4899` |
| 背景（app/file） | `#241E45` → `#141027`                |
| 节点/高光        | `#EDE9FF`、白色透光 `opacity 0.3`     |
| 托盘深色版       | `#2A2342`                               |
| 托盘浅色版       | `#FFFFFF`                               |

与项目深色 Mica UI（`#161616`）及 ComfyUI 紫色品牌系保持一致。
