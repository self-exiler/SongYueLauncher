## 三、遗留未修的可选级缺陷（按价值排序）

1. **导出 ps1 在 Windows PowerShell 5.1 下必死**：`$ErrorActionPreference='Stop'` + `2>&1` 首条 stderr 即终止（`Ps1ScriptBuilder.cs:38,56`）。修法：该行包 try/catch。目标用户大概率用 5.1，建议尽快修。
2. **git pull 走 clone 时固化的 origin**：换镜像/改 RepoUrl 后 pull 仍走旧地址（`RepoService.cs` pull 分支）。修法：`git pull --ff-only {当前镜像URL} HEAD`。
3. **强覆盖更新后旧 .git 覆盖版本号**（`RepoService.RobocopyUpdateAsync` + `AppServices.RefreshVersionFromGitAsync`）：目标是 git 检出时顺带删 `.git`。
4. **AI 入口 UI 冻结**：`AiGatewayService.Current` 每次访问同步 spawn `node --version`；一次点击 2-4 次（`LogPage.AiAnalyze_Click`）。修法：取一次复用 + 秒级缓存。
5. **性能小项**：ErrorGrouper O(n²)（UI 线程）、ArgsPage.BuildRow 每行全表重排 O(n²)、LogPage 每次进入全量重建、AiAnalysisDialog 每增量全文重设 Markdown（需 200ms 节流）、BoundedAnsiConsole 头删 O(n)。
6. **同秒两次启动覆盖日志文件**（`LogService.StartSession` 秒级文件名）。
7. **AppStateMachine 无锁**（跨线程 Report 极端交错丢一次通知）、**ProcessService 输出回调无串行化门**（与 ProcessRunner 的 emitGate 契约不一致）。
8. **OSC-8 超链接等 ANSI 序列未剥**（`AnsiStripper` 只认 SGR），经 comfy-cli/uv 拉起的日志会带控制符进 prompt。
9. **MaxToolRounds=2 与提示词"最多一轮联网"不一致**（客户端已有总次数兜底 6 次，但口径仍漂移）。
10. **工具轮正文无分隔粘连**（进工具轮时 builder 追加 `\n\n`）。
11. **机器级 TRITON_CACHE_DIR 语义分歧**（启动器覆盖继承值、导出脚本保留）。
12. **WindowMinSize 删除后**：AI 分析窗口 760×560 / 主窗 640×480 最小尺寸改用 `OverlappedPresenter.PreferredMinimum*`，需真机拖拽验证生效（WinAppSDK 1.8）。
13. 通用包安装/卸载忽略退出码、VerifyPython 无超时防重入、DetectTools 不占任务槽、PythonBox 清空后自动回填、外部清单容错与内嵌不一致（少 FlexibleStringConverter）、robocopy `-1` 下界、System.Management 9.0.0 升 10.x。
